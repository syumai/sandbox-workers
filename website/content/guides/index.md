These guides show you how to solve specific problems with sandbox-workers. Each guide focuses on a particular task and links to the API reference and concepts pages for the underlying details.

- [Deploy a runtime Worker](/guides/deploy): create a private runtime Worker with a deploy button or the CLI.
- [Execute code](/guides/execute-code): run stateless code with the free `runCode` function and handle results and errors.
- [Use code contexts](/guides/code-contexts): keep state between executions with a durable REPL bound to a runtime Worker.
- [Manage files](/guides/manage-files): read, write, and organize files under `/workspace`.

## Related resources

- [API reference](/api): complete method documentation.
